## 🧐 What Am I Looking At?

Think of the neural network like a team of workers:

1. **First row of workers** looks at the pixels of each digit.
2. **Middle workers** combine those pixels into patterns (like "this looks like a loop" or "this looks like a straight line").
3. **Final worker** makes the decision: "I think this is a 3!"

The program shows you exactly what each worker is "seeing" at every moment. That's what makes it so educational – you can literally see how the brain breaks down a problem.
